# Mäuse 1.5.0 website update plan

Analysis only. No site copy has been changed yet.

This plan is the gap between the **live marketing site** (`michaeldiestelberg/maeuse`, `main` at `cef3c8f`) and **iOS 1.5.0** (`michaeldiestelberg/maeuse-ios`, `main` at `0c7aa0d`, build 64). It covers everything user-facing that changed since the last website update (the 1.4.0 privacy/support wording on 27 Sep 2026), plus one missed 1.4.0 changelog backfill.

Publish these website changes **with** the App Store release of 1.5.0, not before. Until then the live app still matches the 1.4.0 consent wording.

## How to read this

Each item has:

- **Priority** — P0 ship-with-1.5.0 (legal or factually wrong), P1 marketing truth, P2 mockup/visual, P3 nice-to-have
- **File** — the website file to edit
- **Now** — quoted current copy
- **Change to** — concrete EN + DE
- **Why** — which app change it reflects

Legal items that App Review and the in-app privacy links will hit first are marked **Legal**.

| --- | --- | --- |
| Badge | Free / Kostenlos | Recommended / Empfohlen |
| Accuracy | Misunderstands more often; check every draft | Most accurate |
